# AKATSU App
تطبيق Flutter مستقل (بدون واتساب ولا سيرفر) فيه أوامر البوت المحلية.

## الأوامر
كت، عواصم، تاريخ، فكك، ايموجي، انمي، احزر، اكس_او، تخمين، حجر/ورقة/مقص، نرد، عملة، رقم، وقت، نقاطي.

## بناء الـ APK
1. ارفع المشروع على GitHub (مستودع جديد).
2. تبويب Actions ← Build APK ← Run workflow (أو يشتغل تلقائياً عند الرفع).
3. بعد ما ينتهي، نزّل `akatsu-apk` من قسم Artifacts، وفيه `app-release.apk`.

ملاحظة: مجلد `android/` يتولد تلقائياً أثناء البناء.
